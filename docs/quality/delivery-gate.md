# Release gate

Release evidence must identify the commit, assembly version, test outcome, Rhino/Radiance versions, asset bundle, and reference inputs. A release candidate needs a clean Release build and automated checks, Rhino placement/persistence/wiring smoke test, a numerical reference for each changed simulation path, compatibility review for GUID/parameter/manifest/cache changes, and staged-package review that the plugin, core assembly, manifest, and assets are from the same build.
